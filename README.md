# 🚀 Digital Tools Marketplace
🔗 Live Demo
👉 https://digitoolsmarketplace.netlify.app/

## 📌 Project Overview
Digital Tools Marketplace is a modern, responsive web application built using React.js that allows users to explore and manage various digital products in a structured and user-friendly interface. The application simulates a real-world marketplace where users can browse products, add them to a cart, and proceed to checkout with interactive feedback.
## 🎯 Key Features
### 🧭 Navigation & Layout
- Fully responsive Navbar designed according to Figma
- Cart icon integrated with dynamic product count
- Clean and modern UI across all sections (Banner, Stats, Steps, Pricing, Footer)

### 🛍️ Product Management
- Dynamic product listing using JSON data (6–10 products)
- Each product includes:
- Name, description, price, period
- Tag & tag type (e.g., popular, best seller)
- Feature list and icon
- Products displayed in a responsive 3-column card layout

### 🔄 Section Toggling
- Interactive toggle system:
- Product Section (default view)
- Cart Section (shows empty message initially)
- Smooth UI switching between sections

### 🛒 Cart Functionality
- Add products to cart with toast notifications
- Remove individual products from cart
- Display total product count dynamically
- Cart items include:
- Name, icon, price
- Remove button
- Proceed to Checkout button
- Clear cart functionality after checkout

### 🔔 Notifications
- Integrated React-Toastify for:
- Add to cart
- Remove from cart
- Checkout actions

### 📊 Additional Sections
- 📢 Banner with heading, description, image, and CTA button
- 📈 Stats section for showcasing key metrics
- 🪜 Steps section explaining workflow/process
- 💰 Pricing section with structured plans
- 📄 Footer with essential links and information

### 🛠️ Technologies Used
- Frontend: HTML5, CSS3
- Framework: React JS
- Styling: Tailwind CSS, DaisyUI
- Routing: React Router
- Notifications: React-Toastify

### 📱 Responsiveness
#### Fully responsive design for:
- Mobile 📱
- Tablet 📲
- Desktop 💻

### ⚡ Challenges & Solutions
- Implemented dynamic cart state management
- Handled add/remove functionality efficiently
